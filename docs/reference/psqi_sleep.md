# Simulated PSQI and actigraphy data of the worked example

The simulated data set analysed in the manuscript, generated by
\`simulate_sleep_data(seed = 20261003)\`: seven PSQI component scores,
the PSQI global score, an actigraphy sleep-quality index and the true
latent trait. \[sleep_data()\] returns it without \`eta_true\`, and
\[sleep_eta_true()\] returns \`id\` and \`eta_true\`.

## Usage

``` r
psqi_sleep
```

## Format

A data frame with 1000 rows and 11 columns:

- id:

  person identifier, 1 to 1000

- C1:

  PSQI component 1, subjective sleep quality (0 to 3)

- C2:

  PSQI component 2, sleep latency (0 to 3)

- C3:

  PSQI component 3, sleep duration (0 to 3)

- C4:

  PSQI component 4, habitual sleep efficiency (0 to 3)

- C5:

  PSQI component 5, sleep disturbances (0 to 3)

- C6:

  PSQI component 6, use of sleeping medication (0 to 3)

- C7:

  PSQI component 7, daytime dysfunction (0 to 3)

- PSQI_global:

  PSQI global score, the sum of C1 to C7 (0 to 21)

- SQI:

  actigraphy sleep-quality index, higher = better sleep, rounded to 0.1

- eta_true:

  true latent sleep-disturbance trait, N(0, 1); for evaluation only

## Source

Simulated: \`simulate_sleep_data(seed = 20261003)\`, GRM items of
\[true_items\] and SQI = 72 - 8 eta - 1.5 eta^2 + N(0, 6^2).
