# True item parameters and simulation scenarios of the sleep example

\`true_items\`: the seven PSQI-component GRM items of the simulated
sleep example (slopes a, thresholds b, intercepts d = -a b).
\`scenarios\`: the six data-generating models of the simulation study,
each a list(label, m = true mean curve, sd = true residual SD function,
ld = local dependence). They are truths only; no analysis model assumes
their shape.

## Usage

``` r
true_items

scenarios
```

## Format

lists
