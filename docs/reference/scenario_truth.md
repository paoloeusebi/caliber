# Truth of a scenario

True threshold locations m(b_jk) and the true probabilistic crosswalk
with the marginal SQI density on a grid (quadrature: 61 nodes for eta x
21 for u).

## Usage

``` r
scenario_truth(s, grid)
```

## Arguments

- s:

  scenario index

- grid:

  SQI grid

## Value

list(thr, cw, wt)
