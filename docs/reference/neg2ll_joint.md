# Joint deviance of items and digital measure

\\-2 \log L(C, y)\\ with \\\eta\\ integrated out, for any (a, d, act).

## Usage

``` r
neg2ll_joint(Y, sqi, a, d, act)
```

## Arguments

- Y:

  item responses

- sqi:

  the digital measure

- a, d:

  item slopes and intercepts

- act:

  curve object (\[monospline_act()\])
