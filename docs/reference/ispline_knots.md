# Interior knots for the I-spline curve

Ramsay's preliminary placement: one knot at the median, two at the
terciles, three at the quartiles, and so on, here of the latent N(0, 1).

## Usage

``` r
ispline_knots(n_knots)
```

## Arguments

- n_knots:

  number of interior knots

## Value

sorted interior knots on the latent scale
